Growth (Kelly) strategy The growth-optimal (Kelly) portfolio maximizes the expected log of wealth, which equals the long-run compound growth rate. A smaller fraction is more conservative; full Kelly (100%) is aggressive and amplifies estimation error.
Black-Litterman (LLM) strategy The research agent (LLM via LLM_BASE_URL / LLM_MODEL env vars) studies each asset’s news, analyst consensus and earnings through the local Chrome web-search MCP, reasons with the selected effort, and returns a forecast contract — per asset, LLM Samples / Asset times. The sample mean becomes the view, the sample variance its confidence; views blend with the market-equilibrium prior and are cached per day. Agent samples take a few minutes each — lower the sample count or use Direct mode for fast runs. If the LLM or the search server is unreachable, the run degrades gracefully.
⚠️ With Minimal Variance, the Risk-Free Rate does not change the weights — it only affects the displayed Sharpe ratio.
⚠️ Growth (Kelly) maximizes geometric growth; the Risk-Free Rate does not change the weights. Full Kelly is aggressive — half-Kelly (50%) is the recommended practical default.
⚠️ Black-Litterman (LLM) calls the configured LLM once per sample per asset — expect a short wait and possible API cost. The Risk-Free Rate is still used by the final optimizer, not by the LLM views.
